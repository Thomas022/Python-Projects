Project reference

The shop assistant.

Evidence
final-project/documents/ supplies the facts. Source labels identify filenames and paragraph numbers.
Scope
cost and receipt. Other forms are refused in this first version.
Run boundary
check_evidence decides whether generation is allowed. check_answer checks the quoted claim and exact citation before release.
Evaluation boundary
evaluate.py reads cases.json, invokes the application, and compares actual status and answer with fixed expectations. The application does not read the references.
Generation
Default fixtures make no Gemini calls. --mode live uses your saved root .env and Gemini configuration. Strict quote validation may reject correct paraphrases.
Tracing
Enabled LangSmith tracing uploads graph state in fixture and live modes. Existing terminal exports override .env values.
.venv-langgraph/bin/python final-project/app.py cost
.venv-langgraph/bin/python final-project/evaluate.py

Run from the learn directory. Restore the starter $5 policy before the baseline suite. Review intentional policy changes before updating reference answers.
