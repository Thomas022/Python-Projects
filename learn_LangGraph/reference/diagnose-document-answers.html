Quick reference

Locate the first mismatch.

  1. Question → retrieval output: does the passage answer the question? Irrelevant or missing evidence points to a retrieval problem to investigate.
  2. Retrieval output → generation input: did the passage arrive correctly? A mismatch points to a state or wiring problem to investigate.
  3. Generation input → generation output: does the answer agree with the evidence? Correct evidence followed by an unsupported claim points to a generation problem to investigate.

A trace shows what happened in a run. Use the question and source documents to judge whether it was correct. A citation label is not sufficient evidence by itself.

Fix the earliest visible problem, rerun the same question, and compare. One successful example does not prove correctness for every question.
