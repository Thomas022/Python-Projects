Bounded generation retries

When accepted evidence supports the question but the draft disagrees with that evidence, retry generation using the accepted passage. Keep a separate count for generation attempts.

attempts
Retrieval calls, including the first retrieval. Maximum 2 in Lesson 13.
generation_attempts
Generation calls, including the first draft. Maximum 2 in Lesson 13.
passage
The evidence retained across generation attempts.
draft
The latest generation output. Each retry replaces it.
answer_ok
Whether the current draft has been accepted. Generate resets it to False; check_answer evaluates the new draft.

The answer router checks acceptance before the generation limit. Accepted second drafts reach release; rejected second drafts reach reject_answer. Repeating generation can repeat an error, so a bounded retry guarantees termination here, not correctness.
