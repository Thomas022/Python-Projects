Quick reference

Inspect a trace

Save your key once in the project-root .env file. Every Python lesson loads it with python-dotenv before creating its graph. Set LANGSMITH_TRACING=true or false there to enable or disable uploads. Existing terminal exports take precedence; use a fresh terminal to pick up saved values without old overrides. Keep .env local and excluded from Git.

LANGSMITH_TRACING
Set to true to enable tracing; false to disable it.
LANGSMITH_API_KEY
Authenticates your tracing requests. Enter it locally.
LANGSMITH_PROJECT
Groups traces under a chosen name. Agent-based workspaces can create a corresponding agent and Production environment.
LANGSMITH_ENDPOINT
API server for the account’s deployment. Default: GCP US.
LANGSMITH_WORKSPACE_ID
Selects the workspace when the key is scoped to multiple workspaces.

Follow evidence: retrieval output → generation input → generation output.

A local answer does not prove that tracing uploaded successfully. A recorded trace does not prove that its answer is correct.

Use Details view to inspect node inputs and outputs. Our toy graph has no model call, so expect graph and node runs rather than LLM token usage.
