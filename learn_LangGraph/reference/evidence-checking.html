Quick reference

Record a check, then route.

retrieve → check_evidence → generate or fallback

# The check node returns state updates:
{"evidence_ok": False, "reason": "No passage was retrieved."}

# The router returns a destination:
return "generate" if state["evidence_ok"] else "fallback"

Connect retrieve to check_evidence with a fixed edge. Connect check_evidence to a router with a conditional edge. LangGraph applies the check’s update before calling that router. See the official conditional edges guide.

  1. Compare the question with retrieval’s passage.
  2. Compare the check’s decision with that passage.
  3. Compare the selected path with the stored decision.
  4. If generation runs, compare its answer with its evidence.

A check can be wrong. Lesson 7’s exact-phrase rule can reject useful wording or accept misleading text. Fallback prevents an answer on rejected evidence; it does not fix retrieval.
