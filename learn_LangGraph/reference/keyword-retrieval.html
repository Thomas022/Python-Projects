Quick reference

Question → passage → answer.

Retrieval
Search available passages using the question. Return the selected passage and its source.
State update
LangGraph applies a node’s returned updates to state. The next node receives the updated state. In this example, keys without custom reducers are replaced when updated. Official reducer documentation.
Generation in lesson 4
Quote the retrieved passage and source. If the passage is empty, report that no matching passage was found.
Keyword search limitations
Our example matches exact lowercase words, takes the first matching document, and misses synonyms. A missed match does not prove the information is absent.

When checking a trace, compare retrieval output with generation input. When checking answer quality, also ask whether that passage actually answers the question.
