Check the draft against accepted evidence

Evidence checking asks whether a passage answers the question. Answer checking asks whether the generated draft follows that evidence and includes its source.

Keep passage, draft, and answer in separate state fields so a failed draft can be inspected without being released as the answer. A node writes answer_ok; a conditional edge reads it and routes to release or rejection.

Lesson 11 requires an exact quotation with its citation. Equality is sufficient for that format, but rejects paraphrases. A citation-only check cannot detect a changed price. Neither check establishes the underlying document’s truth.
