Project reference

The interface preserves the release boundary.

.venv-langgraph/bin/python final-project/chat.py
# Optional Gemini session:
.venv-langgraph/bin/python final-project/chat.py --live
Inputs
cost or receipt; other question forms can be refused. /help prints help; /quit exits.
Fresh state
Each question supplies only question and mode. No conversation memory or previous draft is supplied.
Display
Print the graph’s final answer and status. A rejected draft belongs in diagnostic tools, not the answer shown to the user.
Generation
Fixtures by default; Gemini only with --live. Both use the same graph checks and root .env. Tracing uploads graph state when enabled.
Verification
Exercise mixed supported/unsupported questions through the interface; run evaluate.py for the separate 7/7 graph baseline.
