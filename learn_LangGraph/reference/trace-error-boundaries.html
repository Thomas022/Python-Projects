Find the first wrong step

Inspect executed nodes in order. Compare each node’s input with the update it returns. Find the earliest update that introduces an unsupported value or an incorrect decision.

Wrong passage accepted
Check the question, passage, and check_evidence’s decision.
Correct passage, wrong draft
Compare generate’s input passage with its output draft. Generation introduces the error.
Wrong draft released
Inspect check_answer’s decision too: it may have missed an earlier generation error.
No cost evidence
Check the visited nodes. Fallback can follow two evidence checks without any generation or answer checking.

Fields that a node does not update retain their previous values in this graph. A $50 draft does not overwrite a $5 passage. A refusal in answer does not erase the rejected draft.
