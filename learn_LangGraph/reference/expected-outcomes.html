Expected versus actual

Case
Saved input and expected behavior.
Evaluator
A function comparing actual output with the criterion.
Passing case
Actual behavior matches the expectation. Rejection can be correct.
Regression
A change breaks behavior that previously met its expectation.

Keep expectations fixed when comparing implementations. Run every case with fresh state. An outcome-only check cannot prove answer correctness.
