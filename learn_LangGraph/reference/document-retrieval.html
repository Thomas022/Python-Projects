From files to context

Document
A file containing evidence.
Passage
A retrievable piece of text; these examples split on blank lines.
Source label
Filename and paragraph number, kept alongside text. Paragraph numbers change when paragraphs are inserted.
Lexical score
Count of shared distinct normalized words. A positive score does not establish relevance.
Context
Selected passages formatted with source labels for a future model input.

loaded ≠ relevant ≠ sufficient ≠ correct answer

No match means this retriever found nothing; it does not prove the documents lack an answer. Context ready means text was assembled; it does not authorize releasing an answer.
