EvaluatorActual status and answer versus fixed expectations. Inspect the reference if the current-evidence answer is valid.

A rejecting node detects an issue; it may not be the node that introduced it. A rejection can pass evaluation. A valid answer can fail a stale reference.

Use the trace’s node inputs and outputs to support your diagnosis. A successful execution indicator does not establish factual correctness. Fixture generation has no Gemini call. Local evaluation is separate from a LangSmith experiment.
