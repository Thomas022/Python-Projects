GEMINI_API_KEY
Authenticates model calls. Save once in .env.
LANGSMITH_API_KEY
Authenticates trace uploads. It does not authenticate Gemini generation.
GEMINI_MODEL
Selects a Gemini text-generation model. This lesson defaults to gemini-3.5-flash-lite.
