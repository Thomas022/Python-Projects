Quick reference

Retry with a stopping rule.

# Start with attempts = 0.
# retrieve returns attempts + 1, passage, and source.
# check_evidence checks every new passage.

if state["evidence_ok"]:
    return "generate"
if state["attempts"] < MAX_ATTEMPTS:
    return "retrieve"
return "fallback"

MAX_ATTEMPTS = 2 means one initial retrieval plus one retry. Accepted evidence can reach generation on the last allowed attempt. Rejected evidence at the limit reaches fallback.

Return both passage and source for every retrieval, including empty results, so the source belongs to the current passage. Recheck after each retrieval. In this example, default state updates replace returned fields and preserve omitted fields; see the official state update guide.

A loop is a conditional edge back to an earlier node. A retry may help when it changes which evidence is retrieved; it does not guarantee useful evidence. Keep an explicit attempt limit. LangGraph’s separate recursion limit counts graph super-steps, not retrieval attempts.
