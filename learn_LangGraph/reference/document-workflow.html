Quick reference · Introduced terms

Document answering

Question → retrieve passages → generate answer → return sources

Retrieval
Finding document passages relevant to a question.
Generation
Using a model to compose an answer from the question and supplied passages.
State
Shared data used by the graph: here, question, passages, sources, and answer.
Node
A function that performs a step and returns state updates.
Edge
A connection determining which node runs next.
Trace
A record of an instrumented execution, including the steps’ inputs and outputs.

Debugging order: inspect the retrieved passages, then the generation input, then the answer. Correct evidence with an incorrect answer points toward generation; irrelevant evidence warrants investigating retrieval first.

Source references identify evidence; verify that it actually supports the answer.
