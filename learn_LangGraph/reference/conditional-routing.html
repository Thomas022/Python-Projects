Quick reference

Choose the next node.

A node returns a dictionary of state updates. A routing function reads current state and returns the destination name.

def choose_next(state):
    return "generate" if state["passage"] else "fallback"

builder.add_conditional_edges("retrieve", choose_next)
builder.add_edge("generate", END)
builder.add_edge("fallback", END)
  1. Retrieval returns its update.
  2. LangGraph applies that update to state.
  3. The router reads that state and selects a destination.
  4. The selected node runs and returns its own update.

Register both destination nodes before compiling. Replace the fixed edge from retrieval with the conditional edge; keeping both can run both paths. See the official edges guide.

An empty passage selects fallback in this example. A nonempty passage selects generation, even if that passage is irrelevant. Check relevance separately using the question and the passage.
