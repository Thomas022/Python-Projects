Summarize what happened

Today’s win: turn the final state into a short report of the work done and how the run ended.

Quick recall

Does keeping a rejected draft automatically stop the same mistake?

Check

No. History lets us inspect earlier attempts. Generation must use feedback or history to change its behavior.

1 · One report for every ending

Add summarize after each existing ending. Release, reject_answer, and fallback set an outcome before reaching the same reporting node.

release       → outcome = "released"       → summarize → END
reject_answer → outcome = "draft_rejected" → summarize → END
fallback      → outcome = "no_evidence"    → summarize → END

Summarize is now the last executed node in every mode. The outcome field preserves why the run ended. A summary reports what happened; it does not change the answer or acceptance decision.

2 · Count from state

history = state["draft_history"]
summary = {
    "retrievals": state["attempts"],
    "generations": state["generation_attempts"],
    "checks": len(history),
    "rejected_drafts": sum(not entry["accepted"] for entry in history),
    "outcome": state["outcome"],
}
return {"run_summary": summary}

Each history entry represents one answer check. The sum counts rejected entries: not False is True, which contributes 1; not True is False, which contributes 0. Checks here means answer checks, not evidence checks. Generations and answer checks match in this graph because every generated draft goes straight to check_answer.

4 · Follow repair before and after

  1. After the two checks: generation_attempts is 2; history decisions are [False, True].
  2. Release: answer becomes the $5 draft and outcome becomes released.
  3. Summarize: reads those fields and creates run_summary with 2 retrievals, 2 generations, 2 checks, and 1 rejected draft.
  4. At END: answer still says $5. The report records that one earlier draft failed.

Missing instead has an empty draft history: zero generations, zero answer checks, and zero rejected drafts. Its outcome is no_evidence. Zero rejected drafts alone does not prove that an answer was released.
