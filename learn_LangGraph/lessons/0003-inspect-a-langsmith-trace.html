LangGraph + LangSmith · Lesson 03 · 10 minutes plus account setup

See the state travel.

Today’s win: find the passage in retrieval’s output, then find the same passage in generation’s input in a real LangSmith trace.

Recall

Retrieval supplies the passage. LangGraph adds it to shared state. Generation receives that updated state. A trace lets you inspect this journey.

You’ll use the same Python graph. Your current passage says 14 days. Retrieval and generation are still simulated; there is no LLM call. LangGraph’s built-in tracing records its nodes when enabled. Source: tracing LangGraph.

1 · Get your LangSmith key

Sign in at LangSmith. In Settings → API Keys, create a personal access token for this learning script and copy it. Save it locally in the project’s .env file, keeping it out of Python files and this chat. Official account and key instructions.

2 · Enable tracing

Open .env in the project folder. Paste your key after LANGSMITH_API_KEY= and save it once:

LANGSMITH_API_KEY=your-key-here
LANGSMITH_TRACING=true
LANGSMITH_PROJECT=document-qa-lessons

Every lesson script loads this file automatically with python-dotenv, including in new terminal sessions. The file is excluded from Git. Existing terminal exports take precedence; if you previously exported LangSmith settings, start a fresh terminal to use the saved values.

Region and workspace settings

The default endpoint is GCP US. For a GCP EU account, add this line to .env:

LANGSMITH_ENDPOINT="https://eu.api.smith.langchain.com"

For another deployment, use its API endpoint from the official setup guide. Match the region where you created the account, rather than your physical location.

If your key is scoped to multiple workspaces, copy the intended Workspace ID from Settings → General and set:

LANGSMITH_WORKSPACE_ID="YOUR_WORKSPACE_ID"

Our environment already includes LangSmith. On a fresh setup, install with .venv-langgraph/bin/python -m pip install langgraph langsmith python-dotenv. Source: tracing configuration.

3 · Run your graph

This run sends the example’s question, passage, source, and answer to your LangSmith workspace.

.venv-langgraph/bin/python lessons/0002-first-python-graph.py

Your terminal should print:

Question: How long do I have to return an unused item?
Answer: Unused items can be returned within 14 days of delivery. [Returns policy, section 2]

If you changed the passage again, expect that value instead. A successful terminal answer confirms local execution; check LangSmith separately to confirm the trace arrived.

4 · Follow the passage

  1. Open LangSmith in the workspace associated with your key. In a project-based workspace, open the tracing project document-qa-lessons. In an agent-based workspace, look for the agent created from that name and its Production environment. Source: workspace layouts.
  2. Open the newest trace. Its root is normally named LangGraph. Choose the Details view and expand the run tree. Source: viewing traces.
  3. Select retrieve. Inspect its output: find passage and source.
  4. Select generate. Inspect its input: find the same passage alongside the original question.
  5. Inspect generation’s output: find the answer containing the passage and source.

5 · Read the trace, not just the answer

Which two views show the passage moving between nodes?

Now change the passage from 14 to 21 days in retrieve, predict what the trace will show, and run again. Compare the two traces: the newer retrieval output and generation input should both contain 21 days. The older trace records the earlier run.

No trace appeared?
  • Refresh and check the correct workspace and project or agent.
  • Check that .env is saved in the project root and contains your key and LANGSMITH_TRACING=true. Older terminal exports override saved values; use a fresh terminal if needed.
  • For authentication errors, check the key’s expiration, account region, and workspace scope.
  • For permission errors, check whether your key can create the tracing project. You can use an existing project name you have access to.
  • Check terminal messages for upload or connection errors. Share the error with your teacher after removing any key.

To disable tracing for future runs, edit this line in .env and save:

LANGSMITH_TRACING=false
