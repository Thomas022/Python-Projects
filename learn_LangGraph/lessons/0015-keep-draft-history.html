Keep the drafts you checked

Today’s win: inspect earlier drafts from the final state, even after a retry replaces the current draft.

Quick recall

After repair succeeds, does draft still contain the first $50 answer?

Check

No. It contains the latest $5 draft. Previously, you needed the execution log to see the earlier draft.

1 · Current value and history

Keep draft for the current answer. Add draft_history for a list of checked attempts. Each entry stores the attempt number, draft text, and acceptance decision.

class DraftCheck(TypedDict):
    attempt: int
    draft: str
    accepted: bool

# Inside check_answer, after computing accepted:
entry = {
    "attempt": state["generation_attempts"],
    "draft": state["draft"],
    "accepted": accepted,
}
return {
    "answer_ok": accepted,
    "draft_history": state["draft_history"] + [entry],
    # Other checker updates stay the same.
}

The + creates a new list containing the earlier entries followed by this entry. This example uses ordinary state replacement: the checker returns the complete updated list. Returning only [entry] would lose the previous entries. We do not modify the input list in place.

Record the entry in check_answer so its decision belongs to the draft just checked. A history entry does not mean the draft was released.

3 · Follow repair before and after

  1. Initially: draft_history is [].
  2. First generate: draft becomes $50. History is still empty because the checker has not run.
  3. First check_answer: history becomes [{attempt: 1, draft: "$50…", accepted: False}]. Feedback describes the correction.
  4. Second generate: draft becomes $5. History still contains the checked $50 attempt.
  5. Second check_answer: history contains both attempts, with decisions [False, True].
  6. Release: answer copies the latest $5 draft. The rejected $50 entry remains available for inspection.

The shortened draft strings above show prices; the Python entries store the full text and citation. History is held in this run’s state. This lesson does not save it to disk or add persistence between runs.
