1 · Save the model key once

This lesson uses Gemini’s API. Your LangSmith key authenticates tracing; an Gemini key authenticates generation. Create an API key in your Gemini API account, then add the following settings to the existing project-root .env file. If a setting already exists, edit its value rather than adding a duplicate. Keep your LangSmith settings.

GEMINI_API_KEY=your-gemini-key-here
GEMINI_MODEL=gemini-3.5-flash-lite

Paste the actual key locally, never in chat or a Python file. It loads automatically on later runs. .env.example contains placeholders only. Existing terminal exports override saved settings; use a fresh terminal if necessary.

Use a Google AI Studio project on the free tier with billing disabled. Gemini 3.5 Flash-Lite has free-tier input and output usage, subject to quotas and availability. If you reach a limit, wait for the quota to reset; you do not need to enable billing for this lesson. Official pricing. The sample defaults to gemini-3.5-flash-lite; GEMINI_MODEL lets you choose another Gemini text-generation model you have access to. Primary reading: Gemini generateContent guide.

2 · Add one node

retrieve → check_evidence
accepted → prepare_generation → generate → END
rejected → fallback → END

The new Python example preserves Lesson 22’s narrow cost/receipt checker. Only generate contacts the model. It sends instructions, your question, and the cited context to the Gemini generateContent API. The SDK exposes generated text through response.text. Official Python example.

response = client.models.generate_content(
    model=model_name,
    contents=question_and_context,
    config=types.GenerateContentConfig(
        system_instruction=INSTRUCTIONS,
        max_output_tokens=2048,
    ),
)
draft = response.text

The instructions ask for one short sentence using only the evidence and the exact bracketed source label. A prompt requests this behavior; it does not prove the model followed it. The terminal labels the result Draft (not validated).

Cost should produce a draft stating $5 per order with [shipping.txt#paragraph-2]. Receipt should describe the original receipt requirement with [returns.txt#paragraph-2]. Wording may vary, and the model may make mistakes: compare your actual draft with the original passage. Warranty and insurance skip generate and require no Gemini key.

What should the terminal show?

After a successful cost or receipt request: Node: generate, Status: draft_generated, and the actual draft. For the rejected questions: Node: fallback, Status: evidence_rejected, and no model call. Authentication or network errors are not evidence rejections; resolve the error before recording a generated draft.

Setup and troubleshooting
python3 -m venv .venv-langgraph
.venv-langgraph/bin/python -m pip install langgraph langsmith python-dotenv google-genai

Keep document_search.py and documents/ beside the script. Missing GEMINI_API_KEY: add it once to .env and save. HTTP 400/401/403: check the Gemini key, project permissions, and regional availability. HTTP 429: check free-tier quota and wait for its reset; keep billing disabled. HTTP 404: use GEMINI_MODEL=gemini-3.5-flash-lite and clear old terminal exports. Gemini 2.5 models may be unavailable to new projects. Connection or timeout errors: check your connection. Share the error type without a key. The script makes one request per accepted run, with one SDK attempt and a 30-second timeout.
