Your first Python graph.

Today’s win: run two Python functions in order and explain how the second receives data from the first.

You already identified generation as the place to investigate when correct evidence leads to a wrong answer. Now we’ll build that workflow.

START → retrieve → generate → END

This is a real LangGraph. Retrieval always returns one fixed passage; generation simply quotes it. It does not search files, call an LLM, or create a LangSmith trace yet.

Read the three moving parts

State: a dictionary shared between steps. TypedDict describes its keys for Python tooling; total=False lets keys be absent until a step supplies them. It does not fill in default values.

Nodes: ordinary Python functions that receive state and return updates. Returning only passage and source keeps the existing question. For these fields, a later update to the same key replaces its earlier value.

Edges: connections defining the execution order. compile() prepares the graph; invoke() runs it and returns the final state. Source: Graph API.

Open the full Python example. Read it once, then run it:

"""Real LangGraph execution; simulated retrieval and generation."""
from typing import TypedDict
from langgraph.graph import END, START, StateGraph


class State(TypedDict, total=False):
    question: str
    passage: str
    source: str
    answer: str


def retrieve(state: State) -> dict:
    # Teaching stub: always selects this passage; no search yet.
    return {
        "passage": "Unused items can be returned within 30 days of delivery.",
        "source": "Returns policy, section 2",
    }


def generate(state: State) -> dict:
    # Teaching stub: quotes the passage; no language model yet.
    return {"answer": f'{state["passage"]} [{state["source"]}]'}


builder = StateGraph(State)
builder.add_node("retrieve", retrieve)
builder.add_node("generate", generate)
builder.add_edge(START, "retrieve")
builder.add_edge("retrieve", "generate")
builder.add_edge("generate", END)
graph = builder.compile()

if __name__ == "__main__":
    initial_state = {"question": "How long do I have to return an unused item?"}
    result = graph.invoke(initial_state)
    print("Question:", result["question"])
    print("Answer:", result["answer"])

Expected answer:

Answer: Unused items can be returned within 30 days of delivery. [Returns policy, section 2]
