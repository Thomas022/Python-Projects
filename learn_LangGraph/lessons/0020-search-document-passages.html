LangGraph + LangSmith · Lesson 20 · 10 minutes

Search document passages.

Today’s win: Retrieve a passage from its words rather than a hardcoded question branch.

Recall: what must travel with a paragraph so you can cite it later? Keep its source label.

1 · Give passages a score

Our small search function counts distinct words shared by the question and passage. It ignores common words, lowercases text, and removes a trailing s from words longer than three letters, so cost matches costs. It ranks positive scores, keeps the first result, and breaks ties in the loader’s order.

This is a simple lexical retriever. It searches text you loaded, but it does not understand meaning or synonyms. Production retrieval can use richer lexical or embedding-based approaches. Official knowledge-base tutorial: retrieval.

2 · Run four searches

Use the original files with the shipping price restored to $5. Predict the source for each query.

.venv-langgraph/bin/python lessons/0020-search-document-passages.py "cost"
.venv-langgraph/bin/python lessons/0020-search-document-passages.py "receipt"
.venv-langgraph/bin/python lessons/0020-search-document-passages.py "warranty"
.venv-langgraph/bin/python lessons/0020-search-document-passages.py "shipping insurance"

Inspect search in the shared helper. The entry script prints score, source, and passage.

Check after running

cost selects shipping paragraph 2. receipt selects returns paragraph 2. warranty has no match. shipping insurance selects shipping paragraph 1: both shipping paragraphs share one word, and paragraph 1 wins the tie. Neither explains insurance.

3 · Separate retrieval from evidence

A score above zero means words overlap. It does not mean the passage answers the question. Synonyms can also mislead this retriever: “delivery fee” misses the cost paragraph and selects returns paragraph 1 because it contains delivery. Try that query too.

This search runs locally and does not upload traces. No model or embedding API key is required.

Setup on another computer

From the project root, create a Python environment and install:

python3 -m venv .venv-langgraph
.venv-langgraph/bin/python -m pip install langgraph python-dotenv

Keep document_search.py and documents/ beside the lesson scripts. Save your LangSmith key once in the project-root .env if tracing is wanted. Every entry script loads that path automatically. Existing terminal exports take precedence. Use LANGSMITH_TRACING=false in .env for local practice only.
