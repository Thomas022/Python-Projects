3 · Read the question inside the check

The default check supports exactly two questions: “How long does standard shipping take?” and “How much does standard shipping cost?” It reads the existing question field and uses a different rule for each. Other questions are rejected.

question = state["question"]
if question == DURATION_QUESTION:
    accepted = duration_ok
    reason = "The question needs shipping duration."
elif question == COST_QUESTION:
    accepted = "standard shipping costs $" in passage and "per order" in passage
    reason = "The question needs shipping cost per order."
else:
    accepted = False
    reason = "This question is outside the two supported questions."
return {"evidence_ok": accepted, "reason": reason}

The check stores its decision; choose_next reads it and chooses generate, retrieve, or fallback. This separation follows the official conditional-edge pattern. We change the check’s logic without adding a graph node.

A deliberately narrow rule.

This exact-question and phrase check teaches the difference between duration and cost. Different wording, negation, or conflicting passages can defeat it. It is not a general evidence validator. All documents and answers here are local teaching examples; no model runs.
