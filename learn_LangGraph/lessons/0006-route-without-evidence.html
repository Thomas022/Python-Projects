Route when evidence is missing.

Today’s win: make your document assistant choose between quoting a retrieved passage and reporting that no passage was found.

Recall from memory

Generation receives a passage saying 3 to 5 business days, then answers 21 business days. Where is the first visible problem? What two values support your diagnosis?

Check your answer

Generation: its input contains 3 to 5 business days, but its output claims 21. This is the fault you repaired in Lesson 5.

1 · Let state choose the next step

In Lesson 4, both matching and unmatched questions reached generate. An if inside that node handled missing evidence. Today we move that choice into the graph: after retrieval, run generate if a passage exists, or run a new fallback node if it does not.

Passage found:  START → retrieve → generate → END
Passage empty:  START → retrieve → fallback → END

A conditional edge calls a routing function after a node finishes. That function reads the updated state and returns the next node’s name. See the official conditional edges guide.

def choose_next(state: State) -> Literal["generate", "fallback"]:
    return "generate" if state["passage"] else "fallback"

builder.add_conditional_edges("retrieve", choose_next)

Python treats an empty string, "", as false. A nonempty passage chooses generate. Literal lists the two possible return values; it does not make the decision. The router returns a node name, while the nodes return dictionaries that update state.

The old builder.add_edge("retrieve", "generate") is absent. Keeping it would also schedule generation, even when the conditional edge selects fallback. Use one routing mechanism from retrieval, as explained in the official edges guide.

2 · Follow one missing-evidence run

  1. Before retrieval: state contains question: "Is there a warranty?".
  2. After retrieval: state still contains that question, plus passage: "" and source: "".
  3. At the choice: choose_next reads the empty passage and returns "fallback". It adds no state fields.
  4. After fallback: state also contains answer: "I could not find a matching passage in these documents.". Generation did not run.

This reports what retrieval found in our small document collection. It does not claim that a warranty does not exist.

A limit to remember

This router checks only whether a passage exists. A shipping question that receives the irrelevant returns passage from Lesson 5 Case A would still reach generation. A nonempty passage does not prove relevance. Keep using your question → passage and passage → answer comparisons.
