Follow the evidence.

Your goal: answer questions from documents. Today’s win: identify the two steps your assistant needs, and locate a failure between them.

One question, two steps

Document: Returns policy, §2

“Unused items can be returned within 30 days of delivery.”

Question

“How long do I have to return an unused item?”

Retrieve: find a relevant passage and preserve its source. Generate: give the question and that passage to a language model to compose the answer. This is a simple form of retrieval-augmented generation (RAG). Source: retrieval guide.

Question → retrieve → generate → answer + source

For this example, a supported answer is: “Within 30 days of delivery [Returns policy, §2].” Supplying a passage does not guarantee a correct answer; checking that the answer matches its evidence is part of the task.

Where the two tools fit

LangGraph connects the steps. Each step is a node; the connection between steps is an edge. The question, retrieved passages, and eventual answer travel through a shared state. Nodes can run ordinary code or call a model. Source: Graph API.

LangSmith records an instrumented run as a trace. You inspect the retrieval output and the generation input/output to see where a problem arose. A trace helps you investigate; it does not itself establish that an answer is correct. Source: tracing quickstart.
