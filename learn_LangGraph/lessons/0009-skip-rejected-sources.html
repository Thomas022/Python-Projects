1 · Replace the scripted switch

Lesson 8 chose Case A’s second document using its attempt number. Now we search a tiny document list using keyword overlap, like Lesson 4. We add tried_sources to state and skip those sources on later attempts. The graph stays the same:

START → retrieve → check_evidence
          ↑          ├─ accepted → generate → END
          └──────────┤─ rejected, attempts < 2
                     └─ rejected, attempts ≥ 2 → fallback → END

Open the Python example. The returns document deliberately has broad keywords, shipping and delivery. The shipping document has shipping and standard. Retrieval chooses the first matching document in list order. A keyword match can still be irrelevant.

2 · Remember a tried source

tried = state["tried_sources"]
for document in DOCUMENTS:
    if state["skip_tried"] and document["source"] in tried:
        continue
    if words & document["keywords"]:
        return {
            "attempts": state["attempts"] + 1,
            "passage": document["passage"],
            "source": document["source"],
            "tried_sources": tried + [document["source"]],
        }

continue skips to the next document. tried + [document["source"]] builds a new list containing the old entries and the current source. We return the complete list: under the default state update rule, this replaces the previous list. LangGraph does not automatically append it.

3 · Follow Case A’s state

  1. Initially: attempts: 0, tried_sources: [], question “How long does standard shipping take?”
  2. First retrieval: the returns document matches “shipping” first. Attempts becomes 1; the tried list contains “Returns policy, section 2”.
  3. First check: rejects the returns passage. The router permits another retrieval.
  4. Second retrieval: skips the returns source, then matches the shipping document. Attempts becomes 2; the list now contains both sources. Shipping passage and source replace the earlier evidence.
  5. Second check: accepts shipping duration, so generation quotes the passage with its source.
Keep the lesson’s limits in mind.

This is local keyword search with two documents; no model or search service runs. Each source names one passage, so skipping a source skips that one passage. The evidence check still only recognizes shipping-duration phrases. It is suitable for these shipping questions, not arbitrary questions. A different document may still be irrelevant.

5 · Remove the useful change

Predict A with skipping disabled, then run:

.venv-langgraph/bin/python lessons/0009-skip-rejected-sources.py a --repeat

Compare both source lines and the final node with normal A. The attempt limit remains 2.

Check after running

Both retrievals return the returns document. Both checks reject it; A reaches fallback. Its tried list contains the same source twice because each retrieval records its result. Increasing the budget would repeat the same first match. The retry needs a change in search behavior to reach different evidence here.
