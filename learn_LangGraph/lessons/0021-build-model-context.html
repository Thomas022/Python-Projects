LangGraph + LangSmith · Lesson 21 · 10 minutes

Build the model context.

Today’s win: Assemble retrieved text and source labels inside a real LangGraph pipeline.

Recall: does a positive retrieval score prove that a passage answers the question? No: shipping insurance retrieved a passage that never discussed insurance.

1 · Connect the pieces

load_documents → retrieve → build_context OR no_context

The graph loads the same files, searches them, and formats a context string. If there are no hits, it routes to no_context. This is the document side of your final assistant. A model call will be added afterward.

Retrieval-augmented generation supplies retrieved context alongside a question to a model. This lesson prepares that context without making a model call. Official tutorial: connecting retrieval to generation.

2 · Follow state updates

  1. Before load_documents: state contains the question. After it: state also contains passages.
  2. Before retrieve: state contains the question and passages. After it: state also contains hits.
  3. Before build_context: state contains hits. After it: state also contains context and status.

The context preserves the source beside the passage:

[shipping.txt#paragraph-2]
Standard shipping costs $5 per order.

3 · Predict and run

.venv-langgraph/bin/python lessons/0021-build-model-context.py "cost"
.venv-langgraph/bin/python lessons/0021-build-model-context.py "warranty"
.venv-langgraph/bin/python lessons/0021-build-model-context.py "shipping insurance"

Compare the visited nodes and final status. With tracing enabled in .env, find lesson-21-context in LangSmith and inspect retrieve output → build_context input. Identify your run by its question and timestamp. Tracing sends these fictional documents and questions to your configured workspace.

Check after running

cost: context_ready with shipping paragraph 2. warranty: no_context and empty context. shipping insurance: context_ready with shipping paragraph 1, even though it does not answer the question.

4 · Name the remaining gap

context_ready means formatting succeeded for a retrieved hit. It does not mean evidence was validated or an answer was generated. Before an answer can be released, we still need a question-aware evidence decision and a generation step. The earlier lessons’ checks remain relevant when the evidence comes from real files.

This is a real LangGraph run with real file retrieval. There is no model call, answer generation, or model-provider charge in this example.

Setup on another computer

From the project root, create a Python environment and install:

python3 -m venv .venv-langgraph
.venv-langgraph/bin/python -m pip install langgraph python-dotenv

Keep document_search.py and documents/ beside the lesson scripts. Save your LangSmith key once in the project-root .env if tracing is wanted. Every entry script loads that path automatically. Existing terminal exports take precedence. Use LANGSMITH_TRACING=false in .env for local practice only.
