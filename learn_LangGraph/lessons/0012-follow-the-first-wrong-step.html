Find where the price first changes

Today’s win: use node inputs and outputs to distinguish the step that introduces an error from a check that catches or misses it.

Recall from memory

What does check_evidence compare? What does check_answer compare?

Check your answer

check_evidence checks the passage against the question. check_answer checks the generated draft against the accepted passage and its citation.

1 · Read before, update, and after

Open the Python example. It reuses Lesson 11’s graph. The new script changes the display, not the graph’s decisions. Every scenario asks B’s cost question.

For each executed node, the terminal shows selected state fields before the node, the update it returned, and the resulting state. An unset field means no value has been written to it yet. Empty passage means retrieval wrote an empty string; these are different situations.

The script uses stream_mode="updates", which yields node updates, then keeps a local copy of state for the display. This works because this graph runs nodes sequentially and replaces each updated field. Other graphs can use reducers or parallel updates, so this display is specific to our example. Official streaming guide.

2 · Follow a caught generation error

The caught scenario means cost evidence is available, the draft changes $5 to $50, and the default answer check runs. Predict the final node before running:

.venv-langgraph/bin/python lessons/0012-follow-the-first-wrong-step.py caught

Find Step 5: generate. Compare BEFORE, UPDATE, and AFTER rather than reading only the final answer.

  1. Before generate: passage says $5, evidence_ok is True, and draft is not set.
  2. Generate’s update: draft says $50. It returns no passage update.
  3. After generate: passage still says $5; draft now says $50. State can hold both values because they belong to separate fields.
  4. After check_answer: answer_ok is False. The error already exists; this check detects it.
  5. After reject_answer: answer contains a refusal. Draft still contains $50 for inspection.
Which observation identifies the first wrong step?

3 · Compare a check that misses the same error

missed uses the same evidence and bad draft, but enables the citation-only answer check. Predict what changes:

.venv-langgraph/bin/python lessons/0012-follow-the-first-wrong-step.py missed
Check after running

Generate still introduces $50. Check_answer now returns answer_ok True because the expected citation is present. Release copies the bad draft into answer. The error begins at generate in both runs; the answer check changes whether it escapes.

4 · Distinguish rejection from missing evidence

missing removes the cost document. Predict which nodes will run:

.venv-langgraph/bin/python lessons/0012-follow-the-first-wrong-step.py missing
Check the visited list
retrieve → check_evidence → retrieve → check_evidence → fallback

The first check rejects duration evidence. The second check rejects an empty passage. Generate and check_answer never run; draft and answer_ok remain not set. Fallback is the intended response to the available evidence.

In the missing-cost run, which node runs twice?

5 · Confirm a faithful run

.venv-langgraph/bin/python lessons/0012-follow-the-first-wrong-step.py good

Before opening the answer below, find generate’s output, check_answer’s decision, and the last executed node.

Check after running

Draft quotes $5. Answer_ok is True. Release writes “Standard shipping costs $5 per order. [Shipping policy, section 2]” into answer.

6 · Inspect the same boundaries in LangSmith

If your Lesson 3 tracing setup is available, set LANGSMITH_TRACING=true in .env and rerun caught and missed. These runs send the toy question, evidence, draft, and answer to your LangSmith workspace. Use Lesson 3’s setup instructions if needed; the local exercises above work without an account.

.venv-langgraph/bin/python lessons/0012-follow-the-first-wrong-step.py caught
.venv-langgraph/bin/python lessons/0012-follow-the-first-wrong-step.py missed

In your configured tracing project, open lesson-12-caught and lesson-12-missed. In Details view, expand the nodes and compare generate’s input and output, then check_answer’s input and output. Find $5 in the accepted passage, $50 in the draft, and the different answer_ok decisions. The terminal log is a local display; confirm separately that the LangSmith traces arrived. Official tracing guide.

Afterward, set LANGSMITH_TRACING=false in .env for subsequent runs:

LANGSMITH_TRACING=false
