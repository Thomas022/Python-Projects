# Mission: Document questions with LangGraph and LangSmith

## Why
Build an assistant that answers questions from documents, while learning how to use LangGraph and LangSmith through practical exercises.

## Success looks like
- Build a workflow that retrieves relevant document passages and uses them to answer a question with source references.
- Inspect a run in LangSmith to distinguish retrieval problems from answer-generation problems.

## Constraints
- Beginner with prior exposure to these topics; implementation experience is not yet established.
- Use short lessons with immediate practice and feedback.
- Use Python for runnable examples.

## Out of scope
- No additional exclusions established yet.
