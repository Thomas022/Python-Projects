# A useful retry changes the selected evidence

The learner correctly reported that normal A reached generation after two different sources, whereas --repeat returned the same evidence twice and reached fallback; B needed one retrieval and C kept an empty tried list after two attempts. They supplied A’s correct sourced answer and described preserving earlier list entries; feedback clarified that retrieval returns the old entries plus the new source. This supports moving to question-aware evidence checking, since topic overlap alone does not establish that a passage answers the question.
